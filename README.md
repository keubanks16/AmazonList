# AmazonList

A parent-controlled Amazon wishlist app.

## Important Amazon limitation
Amazon does not provide a general public API that lets this application silently add items to a personal Amazon shopping cart or wish list. Do not request Amazon passwords, scrape authenticated pages, or claim automatic Amazon syncing.

## Planned flow
- Kids paste Amazon product links and request items.
- Parent reviews requests.
- Parent opens approved products on Amazon and adds them to their Amazon List or Cart.
- No checkout, payment, or ordering capability for children.

## Development
This repository will host the app. A real multi-device version requires secure authentication and a hosted database. A browser-local prototype is not a substitute for those features.
