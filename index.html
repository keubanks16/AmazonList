➕ Add to my list

⚡ Add right from Amazon's Share button

One-time setup on each kid's iPhone or iPad (a parent can do it). After that, on any Amazon item they tap Share → Add to Wish List, and this page opens with the item already filled in.

  1. Tap Copy setup link below.
  2. Open the Shortcuts app → +. Name it Add to Wish List and turn on Show in Share Sheet.
  3. Add the action Get URLs from Input (“Get URLs from Shortcut Input”).
  4. Add the action Copy to Clipboard. It should say “Copy URLs to clipboard”.
  5. Add the action URL and type the setup link into it (pasting can break it).
  6. Add the action Open URLs. It fills in URL by itself.
  7. On an Amazon item: Share → scroll down → Add to Wish List. When this page opens, tap the glowing 📋 Paste link button.

On Android: open this page in Chrome → ⋮ → Add to Home screen / Install. Then Wish List shows up in Amazon's Share menu.
